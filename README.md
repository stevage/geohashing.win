# geohashing.win

Geohashing.win is a data visualisation portal for data about geohashing expeditions.

Information about geohashing generally [here](https://geohashing.site).

A quick summary of this tool [here](https://geohashing.site/geohashing/Maps_and_statistics#geohashing.win).

It is built using Vue, TypeScript, Mapbox GL JS, Map-GL-JS, Turf, Observable Plot, kdbush, and a bunch of things.

All code by Steve Bennett. The site uses relies on fippe.de for the data, which is generated by scraping the Geohashing Wiki.
